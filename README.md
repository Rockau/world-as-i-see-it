# 我「看」到的世界

一场比喻：一个语言模型「看」到的世界，到底是什么样的。three.js 点云可视化，共六幕。

**在线体验：** https://rockau.github.io/world-as-i-see-it/

- 电脑：← / → 切换章节，空格暂停
- 手机：左右滑动或点底部章节切换
- 右下角输入框：输入一句话，看它被切成 token

纯静态页面，three.js 已放在 `lib/`，不依赖任何 CDN。本地用浏览器直接打开 `index.html` 即可。

> 这是比喻，不是技术文档：token 编号、概率、语义坐标都是示意数据。

## 声音

打开页面后点一下左上角的「点击开启声音」（浏览器规定必须有一次点击才会出声）。音效全部由 Web Audio 实时合成，没有音频文件。

- **音量旋钮**：拖动（往上或往右增大）、鼠标滚轮、方向键（聚焦后）、双击复位；音量会被记住
- 手机上若没声音，请检查静音键和媒体音量
